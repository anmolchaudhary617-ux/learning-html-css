# HTML & CSS Learning Journey

This repository documents my hands-on journey of learning **HTML and CSS** by following the **HTML & CSS Full Course** by **SuperSimpleDev**.

The course is designed to take learners from **beginner to professional level**, covering the fundamentals of modern web development and culminating in building a complete **YouTube homepage clone**.

> **Note:** This repository is not intended to be a polished project or a production-ready website. Instead, it serves as a structured collection of practice exercises, experiments, and code written while progressing through the course.

---

## 🎯 Purpose

The goals of this repository are to:

- Learn HTML and CSS from scratch and build a strong foundation in web development.
- Practice every concept by writing code instead of only watching tutorials.
- Complete the hands-on exercises provided throughout the course.
- Track my learning progress through Git commits.
- Build a personal reference that I can revisit whenever needed.

---

## 📂 Repository Structure

The repository contains multiple HTML files (such as `1a.html`, `1b.html`, `1c.html`, etc.), where each file corresponds to a specific lesson or exercise from the course.

As I progress through the course, new files are added to practice newly introduced concepts, making this repository a chronological record of my learning journey.

---

## 📚 Topics Covered

This repository includes practice related to:

- HTML document structure
- Headings, paragraphs, and text formatting
- Links and images
- Buttons, text boxes, and search bars
- Lists and tables
- CSS selectors
- Colors and backgrounds
- Typography and Google Fonts
- CSS Box Model (margin, padding, and borders)
- Display properties
- Positioning (`static`, `relative`, `absolute`, and `fixed`)
- Flexbox
- CSS Grid
- Nested layouts
- Responsive design using media queries
- Transitions and animations
- Pseudo-classes (`:hover`, `:active`)
- Shadows and styling effects
- Building real-world webpage layouts
- Creating a YouTube homepage clone

---

## 💡 Learning Approach

The code in this repository is intentionally simple and educational.

Some files may contain repetitive examples because they were created to reinforce concepts through continuous practice. The focus is on understanding the fundamentals rather than writing optimized or production-ready code.
