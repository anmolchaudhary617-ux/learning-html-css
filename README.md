HTML & CSS Learning Journey: SuperSimpleDev Course
Repository Description This repository documents my hands-on journey of learning HTML and CSS by following the HTML & CSS Full Course by SuperSimpleDev. In this course, the learning path scales from a beginner to a professional level, culminating in building a complete clone of youtube.com
. It is not intended to be a polished project or a complete website. Instead, it serves as a structured collection of practice exercises, experiments, and code written while progressing through the course material.
Purpose
Learn the fundamentals of HTML and CSS from scratch, setting the foundation for becoming a software engineer
.
Practice every concept by writing code instead of only watching tutorials, drawing from the more than 100 exercises provided throughout the course
.
Track my learning progress through incremental commits.
Build a personal reference that I can revisit whenever needed.
Repository Structure The repository contains multiple HTML files (such as 1a.html, 1b.html, 1c.html, etc.), where each file corresponds to a specific lesson or exercise from the course. Every file introduces or practices one or more new concepts learned during that stage, ensuring a hands-on approach to mastering the trial-and-error nature of writing CSS
.
Topics Covered The repository includes practice related to:
HTML document structure (mastering the <!DOCTYPE html>, <html>, <head>, and <body> layout)
.
Headings, paragraphs, and text formatting.
Links and images (using anchor <a> and void <img> elements)
.
Buttons and forms (including text inputs and search bars)
.
Lists and tables.
CSS selectors (targeting classes, elements, and using advanced combinators)
.
Colors (RGB, RGBA, and Hex values) and backgrounds
.
Typography and loading custom web fonts from Google Fonts
.
Box Model (managing margin spacing on the outside, padding on the inside, and borders)
.
Display properties (switching between block and inline-block elements)
.
Positioning (utilizing static, fixed, absolute, and relative positioning)
.
Flexbox for creating highly flexible layouts based on content size
.
CSS Grid for creating precise, perfectly aligned rows and columns
.
Nested Layouts Technique (the core strategy of combining vertical and horizontal layouts to build complex designs)
.
Responsive design using media queries (@media) to adapt layouts for different screen sizes
.
Transitions, pseudo-classes (like :hover and :active), and shadows
.
Basic webpage layouts.
Learning Approach The code is intentionally simple and educational. Some files may contain repetitive examples because they were created to reinforce concepts through continuous practice. The repository prioritizes understanding over optimization or production-ready code.
Intended Use for NotebookLM Use this repository as a reference for:
Explaining what each HTML/CSS file does.
Answering questions about HTML and CSS concepts demonstrated in the code.
Identifying mistakes or suggesting improvements.
Comparing different approaches to solving the same problem.
Summarizing what concepts I have already learned.
Recommending the next topics to study based on my progress, such as diving into JavaScript next to make websites interactive
.
Helping me revise HTML and CSS for interviews, college, or projects.
Context I created this repository as part of my web development learning journey. It represents my own practice code while following the SuperSimpleDev HTML & CSS Full Course, so explanations should focus on helping me understand concepts rather than treating the code as production-quality software
